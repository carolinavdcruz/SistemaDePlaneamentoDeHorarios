    \subsection{Guia de Utilização e Verificação do Projeto}

    \subsection{Pré-Instalação dos Componentes Necessários}

    Antes de se proceder à instalação e execução do projeto, é necessário garantir que todos os componentes de software requeridos se encontram corretamente instalados e configurados no sistema.

    \subsubsection{Configuração do Backend}

    Em primeiro lugar, deve estar instalado o \textit{Java Development Kit (JDK)}, na versão 21 ou superior. Recomenda-se a verificação da versão instalada através do comando garantindo a compatibilidade com as dependências utilizadas no projeto.
    \begin{quote}
        {java --version}
    \end{quote}

    \subsubsection{Configuração da Aplicação Android}

    Para a execução da aplicação, é necessária a instalação do Android Studio, incluindo os respetivos componentes: \textit{Android SDK, Android Emulator e Platform Tools}.
    Estes componentes permitem compilar, executar e testar a aplicação Android, quer através de um dispositivo físico, quer através de um emulador configurado localmente.
    Se for selecionado um dispositivo virtual deverá ser criado com as caracteristicas seguintes para uma melhor experiência:

    \begin{quote}
        {Pixel 6 }
        { Android API 34 ou versão equivalente}
    \end{quote}

    \subsubsection{Configuração da Base de Dados}

    O sistema utiliza uma base de dados PostgreSQL para armazenamento persistente da informação. Assim, deverá estar instalada uma versão do \textit{PostgreSQL }15 ou superior à versão utilizada durante o desenvolvimento do projeto. Com o comando seguinte poderá se verificar a versão:
    \begin{quote}
        {psql --version}
    \end{quote}

    Após a instalação, deverá ser criada uma instância da base de dados e executados os \textit{scripts SQL} disponibilizados no repositório para criação da estrutura de dados necessária ao funcionamento da aplicação.
    \begin{quote}
        {baseDados/schema.sql}

        {baseDados/data.sql}
    \end{quote}
    Relativamente à gestão de dependências e compilação do backend, o projeto utiliza Gradle. No entanto, não é necessária uma instalação manual desta ferramenta, uma vez que o projeto inclui o Gradle Wrapper, responsável por descarregar automaticamente a versão adequada durante o processo de compilação e execução.

    Concluída a configuração do ambiente, recomenda-se a verificação final de todos os requisitos instalados.


    \subsection{Arquitetura Geral}

    \begin{center}
        Android App $\rightarrow$ API REST (Ktor) $\rightarrow$ PostgreSQL
    \end{center}

    \textbf{Fluxo principal:}
    \begin{enumerate}
        \item O utilizador interage com a aplicação Android.
        \item A aplicação comunica com o Backend através da API REST.
        \item O Backend processa os pedidos.
        \item Os dados são armazenados e consultados na base de dados PostgreSQL.
    \end{enumerate}

    \subsection{Casos de Teste Recomendados ao Arguente}

    \textbf{Caso 1 – Login}
    \begin{enumerate}
        \item Abrir aplicação.
        \item Inserir credenciais válidas.
        \item Confirmar acesso.
    \end{enumerate}

    \textbf{Caso 2 – Inserção de Disponibilidade}
    \begin{enumerate}
        \item Adicionar uma nova disponibilidade.
        \item Guardar.
    \end{enumerate}

    \textbf{Caso 3 – Criação de Horário}
    \begin{enumerate}
        \item Executar criação de horário.
        \item Confirmar criação sem conflitos.
    \end{enumerate}

    \textbf{Caso 4 – Persistência}
    \begin{enumerate}
        \item Reiniciar aplicação.
        \item Confirmar manutenção dos dados.
    \end{enumerate}
